# Prajwal Rao — Developer Portfolio

A responsive React + Vite portfolio website.

## Run locally

1. Install Node.js (LTS) if it is not installed.
2. Extract this folder and open it in VS Code.
3. Open the terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
```

The production website is generated in the `dist` folder. You can deploy this project to Vercel or Netlify.

## Before publishing

- Add your GitHub profile URL when ready.
- Review all education dates and project descriptions.
- Add a downloadable resume if you want.
- Confirm the contact details are correct.
